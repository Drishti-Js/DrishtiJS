Drishti JS framework introduces a unified, modern way to build applications using <a href="https://bellard.org/quickjs/"> Quick JS</a> . It supports latest <a href="https://tc39.es/ecma262/"> ECMASCRIPT</a>

Drishti includes its own lightweight runtime, rendering engine, module system, command-line interface, and tooling — all designed to deliver a full-stack experience across web, mobile, desktop, and command-line environments. Its component-based UI model, efficient update pipeline, typed code support, inline css-scss editor, and natural-language-driven AI driven CLI are built to make development intuitive and expressive.

Drishti aims to provide a complete, self-contained ecosystem where developers can create powerful applications with clarity, simplicity, and minimal friction — all powered purely by JavaScript.

Drishti being fullstack either can be run as standalone or can render on the server using node.
